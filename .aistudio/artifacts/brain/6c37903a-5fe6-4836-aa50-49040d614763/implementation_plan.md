# План реализации: Визуальный прототип «Пустая деревня» (Сетка перемещения, 2D-спрайты, компаньоны и интерактивное исследование)

## 1. Контекст и архитектурное видение

На основе ваших ответов:
1. **Перспектива и визуальный стиль:** Сетка перемещения по клеткам (Grid-based 2D Tactical View, классические изометрические/топ-даун пропорции Fallout 1/2, Wasteland) с туманом войны (Fog of War) и пошаговым перемещением/радиусом обзора.
2. **Формат моделей и скетчей:** Стилизованные 2D-спрайты персонажа и питомцев с динамическими силуэтами и скетч-иллюстрациями текущей экипировки (Куртка выжившего, охотничий нож, самодельное оружие, рюкзак).
3. **Первичные интерактивные взаимодействия:**
   - **Исследование и лут:** Осмотр заброшенных домов (изба старосты, кузница, сарай), вскрытие тайников, ящиков и подполов.
   - **Команды компаньону:** Контекстные приказы под уникального питомца (Ермак — залезть в узкую щель подполка, Байкал — взять след мародёров, Каркун — разведка с крыши амбара, Буян — раскопать тайник под бревном, Барсик — почуять скрытые аномалии/радиацию).
   - **Инженерные и полевые задачи:** Осмотр следов мародёров (навык Следопыт), починка сломанного дизель-генератора деревни и настройка радиостанции (навыки Ремонт/Наука).
   - **Стелс и скрытный обход:** Патрульные зоны приближающихся мародёров («Стервятники»), поле зрения врагов, использование укрытий и бесшумный отход к лесной тропе.

## 3. Детализация компонентов и файлов

### Шаг 1: `src/data/villageMapData.ts` (Структура первой локации)
- Описание сетки деревни (12x10 тайлов):
  - Типы тайлов: `ground` (земля/слякоть), `grass` (сухая трава), `path` (тропинка), `wall` (сруб избы), `debris` (завалы досок), `gate` (деревянные ворота), `forest` (граница леса).
  - Интерактивные объекты (POI):
    1. **Изба Старосты:** Запертый сундук (проверка Взлом/Ловкость), стол с оставленными заметками старосты.
    2. **Деревенская кузница:** Верстак с инструментами, сломанный дизельный генератор (требует Repair/Science, запускает аварийный свет).
    3. **Старая радиомачта / узел связи:** Рация на аккумуляторе (навык Ремонт/Электроника, ловит зашифрованный эфир).
    4. **Узкий подпол сарая:** Доступен для хорька Ермака или тонкого щупа, ценный схрон довоенных патронов/деталей.
    5. **Следы у околицы:** Следы тяжелых сапог (навык Следопыт, выявление численности мародёров).
    6. **Патруль мародёров:** 2 кочевых бандита с сектором обзора; возможность обойти скрытно по кустам (Stealth) или отвлечь вороном/шумом.

### Шаг 2: `src/components/visuals/CharacterSprite.tsx` & `CompanionSprite.tsx`
- **CharacterSprite:** Векторный 2D-спрайт выжившего с адаптивной визуализацией:
  - Слой тела (базовый силуэт, пол/телосложение).
  - Слой одежды/брони (Куртка выжившего / комбинезон / бронежилет).
  - Слой оружия в руках (Охотничий нож / пистолет / винтовка / рукопашный хват).
  - Направление движения и индикатор выделения.
- **CompanionSprite:** Детализированный стилизованный спрайт выбранного компаньона:
  - Байкал (пёс с ошейником и сумкой), Барсик (кот с навостренными ушами), Каркун (ворон на жердочке/в полёте), Ермак (хорёк), Буян (кабанчик).

### Шаг 3: `src/components/visuals/VillageTacticalMap.tsx`
- Интерактивная канвас/SVG-сетка с кликабельным перемещением:
  - Клик по соседней доступной клетке перемещает персонажа (с анимацией шага и расходом шагов).
  - Питомец следует за персонажем на расстоянии 1 клетки.
  - Подсветка доступного радиуса взаимодействия (соседние 1–2 клетки для обыска, взлома, ремонта).
  - Отображение конусов видимости врагов (мародёров).
  - Мини-карта / радар сектора в правом верхнем углу.

### Шаг 4: `src/components/visuals/CompanionCommandPanel.tsx`
- Панель тактических действий питомца:
  - Активные кнопки способностей в зависимости от выбранного питомца:
    - **Байкал:** «Взять след» (подсвечивает безопасный маршрут мимо мародёров).
    - **Каркун:** «Воздушная разведка» (открывает скрытые клетки карты на 2 хода и отвлекает часового).
    - **Ермак:** «Обыскать щели» (залезает в труднодоступные разрушенные схроны).
    - **Буян:** «Протаранить завал» (расчищает заваленный проход к погребу кузницы).
    - **Барсик:** «Охотничье чутьё» (предупреждает о ловушках и приближении врагов).

### Шаг 5: `src/components/visuals/InteractionDialogModal.tsx`
- Модальное окно осмотра и действий при клике на объект сетки:
  - Скетч-арт объекта (сундук, дизель-генератор, рация, патруль).
  - Описание текущего состояния.
  - Варианты действий с проверкой навыков через канонический `resolveSkillCheck`:
    - Починить генератор (Repair, DC 16) -> при успехе загораются фонари, даёт XP и запчасти.
    - Взломать ящик старосты (Lockpick, DC 14) -> получение предметов.
    - Скрытно прокрасться мимо мародёра (Stealth, DC 15) -> получение опыта и безопасный проход.

### Шаг 6: Интеграция в `HeaderNav.tsx` и `App.tsx`
- Добавление вкладки **«Тактическая карта: Деревня»** в главное меню.
- Синхронизация полученного лута, опыта и времени с общим состоянием игры (`GameContext`).

## 4. План верификации и тестирования

1. **Проверка перемещения и коллизий:**
   - Персонаж перемещается строго по свободным клеткам, стены и препятствия блокируют проход.
   - Питомец корректно следует за хозяином или выполняет удаленные команды.
2. **Проверка взаимодействий:**
   - Все объекты (генератор, рация, сундук, завал) корректно открывают карточки взаимодействия.
   - Проверки навыков используют существующую механику `resolveSkillCheck` со стандартными модификаторами.
   - Лут зачисляется в инвентарь игрока без дубликатов.
3. **Качество визуализации:**
   - Высокая чёткость SVG/CSS спрайтов, эстетика постапокалиптического реконструктивизма Подмосковья, отсутствие визуальных артефактов и "AI slop" элементов.
4. **Технические проверки:**
   - Запуск `npm run lint` (`tsc --noEmit`).
   - Запуск `npm test`.
   - Запуск `npm run build` (`vite build`).
