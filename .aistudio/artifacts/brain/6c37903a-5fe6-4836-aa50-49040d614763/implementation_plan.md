# План интеграции: Одобренный Канон, Пролог «Пустая деревня» и Базовые предметы (v1.0)

## 1. Резюме задачи и контекст

Пользователь предоставил официальный утверждённый канон и пролог RPG «Out-of-life» (v1.0):
1. **Базовый сеттинг и лор:** ~70 лет после катастроф (аномалии, вирусы), леса Подмосковья. Пост-коллапс Реконструктивизм, изолированные деревни, восстановление технологий (рации и механика). Скрытый глобальный сюжет: изолированный СверхИИ и проект «Золотой Купол» (протагонист о нём ничего не знает).
2. **Система компаньонов (питомцы):** Байкал (сторожевой пёс), Барсик (кот), Каркун (ворон), Ермак (степной хорёк), Буян (сторожевой кабанчик), Одиночка (без питомца).
3. **Структура интерактивного пролога («Пустая деревня»):**
   - **Сцена 1:** Пробуждение (причина обусловлена предысторией).
   - **Сцена 2:** Реакция питомца (демонстрация навыка питомца, вводный туториал).
   - **Сцена 3:** Стервятники (приближение банды мародёров из 5-6 человек).
   - **Сцена 4:** Адреналиновый лут и Побег (проверки Stealth / Sleight of Hand / Search, вынос припасов).
   - **Сцена 5:** Глобальная карта (проверка Следопыт / Survival, открытие пути к Соседнему поселению по Карте Старосты).
4. **Базовый инвентарь:** Карта Старосты, Старый Охотничий Нож, Куртка Выжившего, Жестяная фляга (Кипяченая вода), Сухари, Динамо-фонарь "Жучок".
5. **Точка интеграции в UI:** Стартовый интерактивный пролог сразу после завершения создания персонажа (с возможностью переиграть/перечитать в Журнале / Исследовании).

                                          |
                                          v

## 4. План тестирования и валидации

1. **Модульные тесты (`npm test`)**:
   - Проверка наличия всех 6 канонических предметов в `ITEM_DATABASE`.
   - Проверка экипировки ножа и куртки при старте.
   - Проверка формул урона и защиты без регрессий.
2. **Типизация и линтинг (`npm run lint`)**:
   - `tsc --noEmit` без ошибок.
3. **Сборка приложения (`npm run build`)**:
   - Успешный бандлинг Vite без циклических зависимостей или отсутствующих иконок.
4. **Пользовательский сценарий в UI**:
   - Создание персонажа -> Автоматический запуск Пролога «Пустая деревня» -> Прохождение 5 сцен с D20 бросками -> Переход в инвентарь (проверка наличия Карты Старосты, Куртки, Ножа, Фляги, Сухарей, Фонаря) -> Доступ к Журналу лора.
