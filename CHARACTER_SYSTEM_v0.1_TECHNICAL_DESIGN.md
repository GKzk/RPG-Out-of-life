## 1. Анализ текущей системы характеристик

В текущей кодовой базе (`src/utils/statCalculations.ts`, `src/types/game.ts`) заложена базовая механика:
- Семь атрибутов SPECIAL со значениями от 1 до 10.
- Пул генерации: 40 очков (`SPECIAL_CREATION_POINTS = 40`), стоимость 1:1 до 7, затем 2 очка за 8, 3 за 9, 4 за 10 (`POINT_BUY_COSTS`).
- Механика жестких анти-синергий (`ANTI_SYNERGIES`): например, если `STR >= 8 && END >= 8`, то накладывается штраф `-2 INT, -2 AGI, -1 CHA`.
- Расчет `effectiveSpecial`, который последовательно вычитает штрафы анти-синергий, штрафы дебаффов выживания (голод/жажда/радиация) и применяет баффы препаратов.

### 1.1. Что можно использовать повторно (Keep & Reuse)
1. **Концепт двухслойных характеристик**: разделение на `Base SPECIAL` (неизменяемый генетический костяк) и `Effective SPECIAL` (динамический результат травм, усталости, препаратов, брони и условий среды).
2. **Идея прогрессивной стоимости при генерации (Point-Buy с софт-капом)**: покупка экстремальных значений (8, 9, 10) должна стоить несоизмеримо дороже средних (4, 5, 6).
3. **Общий пайплайн вычисления производных параметров**: паттерн чистых функций `calculateEffectiveSpecial` и `calculateDerivedStats` с детерминированным входом и выходом.

### 1.2. Что необходимо существенно изменить (Refactor)
1. **Механику Anti-Synergies**:
   - *Текущая проблема*: жесткое урезание базовых атрибутов в `calculateEffectiveSpecial` («взял 8 силы и 8 выносливости — потерял 2 интеллекта») ощущается искусственным наказанием и ломает логику билдостроения (игрок видит, что распределил очки в интеллект, а игра их срезает).
   - *Новый подход*: анти-синергии должны работать через **производные параметры, типы проверок и физические ограничения**, а не через грубое списывание очков другого SPECIAL (например, высокий вес мышц и плотность костей снижают скрытность и маневренность, а не абстрактный IQ).
2. **Разрешение проверок и броски кубиков**:
   - В текущем проекте сосуществуют d100 (в навыках и VATS) и d20 (в инициативе и бою). Необходима единая унифицированная система проверок.
3. **Моделирование состояний (Status Effects)**:
   - В текущем коде дебаффы зашиты вручную (`hunger >= 75 ? -2 STR : ...`). Необходима расширяемая шина модификаторов (Modifiers Engine).

### 1.3. Что лучше полностью заменить (Deprecate & Replace)
1. **Линейную процентную систему навыков (0–100%)**:
   - В текущей версии навык 65% означает 65% шанса на d100. Это ведет либо к «save-scumming», либо к обесцениванию проверок при низких значениях. Заменяется на d20 + Модификатор характеристики + Бонус мастерства/ранга навыка против DC (Класса Сложности).
2. **Прямое связывание дебаффов выживания с базовыми статами**:
   - Вместо разрозненных `if (hunger > 50) effectiveStr -= 1` вводится единый реестр состояний персонажа (`Conditions`), генерирующий типизированные модификаторы (`StatModifier`, `CheckModifier`, `ActionModifier`).

### 1.4. Карта зависимостей характеристик в текущей системе
```
Base SPECIAL 
  ├──> Anti-Synergy Rules ──┐
  ├──> Survival Debuffs   ──┼──> Effective SPECIAL
  └──> Drug Modifiers     ──┘          │
                                       ├──> Derived Stats (HP, AP, Carry, Ev, Init, Crit)
                                       ├──> Skills Base % (Formulae: e.g. Lockpick = PER*2 + AGI)
                                       ├──> Combat Mechanics (Hit Chance, VATS)
                                       └──> Action Requirements (Min STR for Weapons)
```

## 2. Проблемы текущей архитектуры и игровой математики

1. **Бинарный тупик прокачки**: игрок либо максимизирует боевой навык до 80–90%, делая проверки тривиальными, либо игнорирует небоевые навыки, упираясь в непроходимые стены квестов.
2. **Иллюзия вариативности проверок**: в текущих диалогах и событиях проверка привязана строго к одному параметру (например, только `Speech` или только `Lockpick`). Отсутствует возможность альтернативного прохождения (открыть дверь ломом, замком, хакерским терминалом или термопастой).
3. **Отсутствие механики «цена успеха»**: текущий бросок — это бинарное `Успех / Провал`. В глубокой RPG необходимы градации: *Полный успех*, *Успех с критической ценой* (дверь открыта, но замок сломан и поднята тревога), *Неудача*, *Катастрофический провал*.
4. **Отрезанность Survival-метрик от тактики**: жажда и голод сейчас являются просто таймерами, отнимающими характеристики, вместо того чтобы влиять на усталость в бою, концентрацию при прицеливании и ментальную стойкость.

## 3. Предлагаемая модель SPECIAL

Базовые характеристики лежат в диапазоне **от 1 до 10** (где **5 — средний взрослый человек пустоши**, **1 — физическое/ментальное увечье**, **10 — биологический или эволюционный пик выжившего**).

### Таблица конвертации SPECIAL в Модификатор проверки (D20 Attribute Modifier)

| Значение SPECIAL | Модификатор D20 | Качественная оценка |
| :--- | :---: | :--- |
| **1** | **-3** | Критическая недостаточность / Инвалидность |
| **2 – 3** | **-2** | Явная слабость / Уязвимость |
| **4 – 5** | **-1 / 0** | 4: ниже среднего (-1); 5: средний уровень (0) |
| **6 – 7** | **+1 / +2** | 6: одаренный (+1); 7: профессионал (+2) |
| **8 – 9** | **+3 / +4** | 8: элита Пустоши (+3); 9: вершина возможностей (+4) |
| **10** | **+5** | Легендарный предел человеческой природы (+5) |

### Подробная декомпозиция характеристик

#### 1. STR (Strength — Сила)
- **Суть**: Мышечная масса, плотность костей, взрывная сила и физический рычаг.
- **Прямые механики**: Переносимый вес (Carry Capacity), минимальные требования тяжелого оружия, базовый урон в рукопашной и холодном оружии, дистанция броска гранат.
- **Косвенные механики**: Сопротивление сбиванию с ног (Knockdown), удержание отдачи автоматического оружия, преодоление завалов.
- **Поддерживаемые навыки**: Тяжелое вооружение, Холодное оружие, Рукопашный бой, Атлетика/Прорыв.
- **Проверки**: Выбивание дверей, поднятие заклинивших решеток, удержание тросов, запугивание физической силой.
- **Влияние на производные**: Базовый HP (незначительно), Melee Damage Bonus, Max Carry Weight.
- **Полярные значения**:
  - *Низкое (1–2)*: Персонаж не может носить тяжелую броню, винтовки требуют упора, переносимый вес мизерен (быстрый перегруз). *Игровая возможность*: уникальные варианты «пролезть в узкую вентиляцию», куда мускулистый громила не поместится; сниженная масса тела не триггерит хрупкие нажимные ловушки-плиты.
  - *Высокое (9–10)*: Стрельба из тяжелых пулеметов от бедра без штрафа, возможность использовать куски арматуры и двери как щиты.

#### 2. PER (Perception — Восприятие)
- **Суть**: Острота зрения, слуха, обоняния, интуитивная реакция на опасность и пространственное чутье.
- **Прямые механики**: Дальность обнаружения врагов и ловушек, точность на дальних дистанциях, базовая Инициатива в бою, шанс заметить засаду до начала боя.
- **Косвенные механики**: Обнаружение тайников на карте, качество распознавания болезней у спутников/NPC, раскрытие блефа собеседника.
- **Поддерживаемые навыки**: Снайперское/Стрелковое оружие, Взлом/Поиск ловушек, Выживание (следопытство), Внимательность/Опознание.
- **Проверки**: Чтение скрытых мотивов, поиск следов на песке, обнаружение растяжек в темноте, чтение стертых надписей на терминалах.
- **Влияние на производные**: Инициатива (основной фактор), Базовый Evasion на дальней дистанции, Радиус обзора/тумана войны.
- **Полярные значения**:
  - *Низкое (1–2)*: «Слепой крот». Ловушки взрываются под ногами, враги всегда имеют ход неожиданности (Surprise Round). *Игровая возможность*: персонаж невосприимчив к ослепляющим гранатам и визуальным галлюциногенам; не отвлекается на ложные шумы; пугающие зрелища расчленения не вызывают падения Морали/Стресса (он просто не видит деталей).
  - *Высокое (9–10)*: Видит скрытые уязвимости врагов (подсветка слабых зон даже без спец-перков), чувствует засады за две комнаты до контакта, читает пульс собеседника.

#### 3. END (Endurance — Выносливость)
- **Суть**: Физиологический запас прочности, метаболическая устойчивость, сопротивляемость токсинам, радиации и лишениям.
- **Прямые механики**: Базовый и приростной запас Здоровья (HP), скорость накопления радиации и токсинов, порог получения глубоких травм (переломов).
- **Косвенные механики**: Время автономности до наступления голодания, обезвоживания и истощения от бессонницы; скорость свертывания крови (естественный реген).
- **Поддерживаемые навыки**: Выживание (устойчивость), Стойкость/Концентрация, Рукопашная защита.
- **Проверки**: Сопротивление газам, марш-броски по радиоактивным барханам, удерживание сознания при пытках или шоке от ранения.
- **Влияние на производные**: Max HP, Скорость деградации Survival-показателей, Пороги токсичности и радиации.
- **Полярные значения**:
  - *Низкое (1–2)*: «Хрустальный больной». Любая царапина грозит заражением крови, глоток нефильтрованной воды дает лучевую болезнь, откат AP замедлен. *Игровая возможность*: сверхчувствительный метаболизм заставляет препараты действовать мгновенно с удвоенной силой (двойная эффективность медикаментов при высоком риске зависимости); врачи и ученые сочувствуют немощному бродяге.
  - *Высокое (9–10)*: Способен пить из луж и переваривать сырое мясо кротокрысов без паразитов, игнорирует легкие контузии, может сутками идти без сна.

#### 4. CHA (Charisma — Харизма)
- **Суть**: Сила личности, психологическое влияние, социальная проницательность, внушение, торговый магнетизм.
- **Прямые механики**: Цены торговцев (Barter Multiplier), мораль и боевая эффективность спутников, начальная реакция фракций и незнакомцев.
- **Косвенные механики**: Возможность избежать боя через переговоры, способность стравливать враждующие группы, получение скидок и эксклюзивных квестов.
- **Поддерживаемые навыки**: Убеждение (Дипломатия), Обман/Блеф, Торговля, Лидерство/Управление стрессом.
- **Проверки**: Убеждение рейдеров сложить оружие, распознавание лжи, торг за патроны, успокоение паникующих выживших.
- **Влияние на производные**: Моральный дух (Resolve/Stress resistance), Скидки торговцев, Максимальный размер свиты/союзников.
- **Полярные значения**:
  - *Низкое (1–2)*: Отталкивающий социопат, немой калека или жуткий мутант. Торговцы задирают цены на 200%, охрана городов хватается за оружие при его приближении. *Игровая возможность*: враги не ожидают от него хитрости и не считают угрозой («жалкий оборванец»); он может безнаказанно воровать прямо из-под носа («на него брезгуют смотреть»); уникальный брутальный диалоговый стиль: запугивание чистой нечеловеческой жутью без слов.
  - *Высокое (9–10)*: Создает культы вокруг себя, вражеские солдаты дезертируют во время переговоров, получает критически важную информацию даром.

#### 5. INT (Intelligence — Интеллект)
- **Суть**: Логическое и дедуктивное мышление, аналитическая память, скорость обучения, понимание технологий Старого Мира.
- **Прямые механики**: Очки навыков при повышении уровня (Skill Points), взлом терминалов, создание сложных модификаций и медикаментов (Crafting).
- **Косвенные механики**: Качество информации в квестовом журнале (тупой герой видит «Иди туда, стукни того», умный видит структурный план базы и слабости проводки).
- **Поддерживаемые навыки**: Наука (программирование/физика), Медицина (диагностика/хирургия), Ремонт (механика/баллистика), Анализ/Оценка.
- **Проверки**: Ремонт генератора базы, перепрошивка боевых турелей, синтез антидота из яда скорпиона, логическая дедукция в расследованиях.
- **Влияние на производные**: Количество доступных слотов активных тактических действий, регенерация очков крафта, бонусы к очкам прокачки.
- **Полярные значения**:
  - *Низкое (1–2)*: «Классический тупица Fallout». Персонаж изъясняется мычанием и односложными фразами («Я бить!», «Где еда?»). Большинство сложных терминалов взрываются при попытке ввода. *Игровая возможность*: уникальные ветки диалогов с безумными супермутантами, роботами со сбоем протоколов и детьми; иммунитет к психологическому манипулированию и когнитивному стрессу (невозможно сойти с ума от экзистенциального ужаса, если ты его не осознаешь).
  - *Высокое (9–10)*: Мгновенный взлом протоколов турелей для зачистки бункера чужими руками; возможность предсказывать траектории снарядов (интеллектуальный расчет баллистики дает бонус к меткости).

#### 6. AGI (Agility — Ловкость)
- **Суть**: Координация движений, гибкость, рефлексы, мелкая моторика, чувство баланса.
- **Прямые механики**: Очки Действия (Action Points) в пошаговом режиме, базовая защита от атак (Evasion/AC), шанс скрытного перемещения (Stealth).
- **Косвенные механики**: Штрафы к перемещению по пересеченной местности, шанс бесшумного открывания дверей, скорость перезарядки оружия.
- **Поддерживаемые навыки**: Легкое стрелковое оружие, Скрытность, Карманная кража/Мелкая моторика, Акробатика/Уклонение.
- **Проверки**: Бесшумное проскальзывание мимо часовых, перехват падающего детонатора, хождение по тонким балкам над пропастью.
- **Влияние на производные**: Базовый пул Action Points (AP), Уклонение (Evasion Modifier), Скорость перемещения в клетках.
- **Полярные значения**:
  - *Низкое (1–2)*: Неуклюжий увалень. Скрипит половицами, ломает отмычки в замках, падает при попытке перепрыгнуть яму. Мало AP (хватает на один выстрел за раунд). *Игровая возможность*: за счет медлительности и низкого центра тяжести крайне устойчив к сбиванию с ног и таранным ударам; компенсирует моторику тяжелым неизбирательным оружием (огнеметы, гранатометы).
  - *Высокое (9–10)*: 12–14 AP в раунд (способен сделать серию выстрелов, перезарядиться и уйти в тень); танцует между очередями противника.

#### 7. LCK (Luck — Удача)
- **Суть**: Квантовая неопределенность, влияние судьбы, статистическая аномалия, спасительное совпадение.
- **Прямые механики**: Базовый шанс критического попадания (Critical Strike Chance), шанс критического успеха/провала на кубиках, генерация редкого лута в ящиках.
- **Косвенные механики**: Вероятность осечки оружия у противника при выстреле в упор, спасительный рикошет при смертельном уроне (Miracle Survival).
- **Поддерживаемые навыки**: Азартные игры, Мусорщик (Scavenging), Интуитивная стрельба.
- **Проверки**: Нажатие случайной кнопки на пульте управления ядерным реактором, выбор правильного провода при обезвреживании бомбы наугад.
- **Влияние на производные**: Critical Chance %, Минимальный гарантированный порог броска (Fate Points).
- **Полярные значения**:
  - *Низкое (1)*: «Проклятый пустошью». Оружие клинит в два раза чаще, патроны в контейнерах оказываются отсыревшими, ловушки срабатывают даже при успешном обходе. *Игровая возможность*: враги рядом с персонажем тоже подвержены казусам; притягивает аномальные события и редких черных торговцев, охотящихся за «мечеными смертью».
  - *Высокое (9–10)*: При стрельбе вслепую пуля рикошетит от ведра и попадает прямо в глаз главарю рейдеров; находит армейские стимуляторы в мусорных баках заброшенного мотеля.

## 5. Универсальная модель RPG-проверок (D20 Core Engine)

В основе всех активных действий лежит классическая вероятностная кривая D20:

$$\text{Roll} = \text{D20} + \text{Attribute Modifier} + \text{Skill Mastery} + \text{Equipment/Tool Bonus} + \text{Condition Penalty}$$

Проверка успешна, если $\text{Roll} \ge \text{Difficulty Class (DC)}$.

### 5.1. Компоненты формулы

1. **D20**: бросок 20-гранного кубика (равномерное распределение от 1 до 20).
2. **Attribute Modifier**: модификатор базовой характеристики (-3 до +5).
3. **Skill Mastery (Ранг владения навыком)**:
   - *Не знаком (Untrained)*: `+0` (для специализированных навыков, таких как Взлом или Хирургия, может накладываться штраф или запрет на проверку).
   - *Новичок (Novice)*: `+2`
   - *Специалист (Adept)*: `+4`
   - *Мастер (Master)*: `+6`
4. **Equipment / Tool Bonus**:
   - Наличие качественных отмычек: `+2` к Взлому.
   - Использование лома при выбивании двери: `+3` к Силе.
   - Работа голыми руками там, где нужен инструмент: штраф `-3` или помеха.
5. **Condition Penalty**:
   - Сильное обезвоживание: `-2` ко всем физическим проверкам.
   - Контузия / повреждение головы: `-3` к ментальным проверкам.
   - Сломанная рука: помеха (Disadvantage) на действия двумя руками.
6. **Advantage / Disadvantage (Преимущество / Помеха)**:
   - При благоприятных обстоятельствах (например, освещенное помещение при ремонте или знание слабости замка) бросаются **2d20 и выбирается лучший результат**. При неблагоприятных (ремонт под пулеметным огнем в темноте) — **2d20 и выбирается худший**.

### 5.2. Градации исходов (Degrees of Success)

- **Критический успех (Natural 20 или превышение DC на 10+)**: задача выполнена безупречно, сэкономлены ресурсы, получен скрытый бонус (найден дополнительный тайник, замок открыт абсолютно бесшумно).
- **Чистый успех ($\text{Roll} \ge \text{DC}$)**: задача выполнена в штатном режиме.
- **Частичный успех / Успех с ценой ($\text{Roll} = \text{DC} - 1 \text{ или } \text{DC} - 2$)**: игроку предлагается выбор: либо провал, либо успех, но с осложнением (дверь поддалась, но отмычка сломалась; генератор запущен, но заклинило реле и пошел дым).
- **Неудача ($\text{Roll} < \text{DC}$)**: действие не удалось, ситуация усложнилась.
- **Критический провал (Natural 1 или провал на 10- ниже DC)**: заклинивание механизма, поломка инструмента, случайный выстрел, травма руки или активация сигнализации.

---

### 5.3. Принцип мульти-путевого разрешения (Multi-Path Solution)

Каждая узловая ситуация в игре проектируется минимум с 4–5 альтернативными путями преодоления.

#### Пример: Запертая гермодверь убежища довоенного образца (DC 15)

```
                              ┌── [STR 8+ / Лом] ──> Выломать гидропривод (Шумно, травма рук при провале)
                              │
                              ├── [Lockpick / Отмычки] ──> Вскрыть механический замок (Тихо, риск сломать инструмент)
                              │
                              ├── [Repair / Паяльник] ──> Перемкнуть сервоприводы питания (Требует деталей)
                              │
[Гермодверь Убежища] ─────────┼── [Science / Терминал] ──> Взломать консоль доступа (Нужен доступ к сети, риск блокировки)
                              │
                              ├── [Explosives / Динамит] ──> Направленный подрыв петель (Шум на весь сектор, разрушение лута)
                              │
                              ├── [Perception 7+ / Осмотр] ──> Найти вентиляционный лаз для персонажей малой комплекции
                              │
                              └── [Speech / Интерком] ──> Убедить охранного робота внутри, что вы инспектор «Волт-Тек»
```

## 6. Производные параметры (Derived Stats)

Анализ существующих производных параметров и предложения по их трансформации:

| Параметр | Статус | Анализ и изменение |
| :--- | :---: | :--- |
| **HP (Hit Points)** | **Изменить** | *Текущее*: $50 + (\text{END} \times 10) + (\text{STR} \times 3)$. *Предложение*: снизить абсолютные цифры для повышения ценности каждого ранения. Базовые HP: $20 + (\text{END} \times 4) + \text{STR}$. Прирост за уровень строго от END. Здоровье не должно исчисляться сотнями — персонаж должен бояться пули. |
| **AP (Action Points)** | **Изменить** | *Текущее*: $5 + \lfloor\text{AGI}/2\rfloor$. Диапазон 5–10 AP слишком сжат (выстрел винтовки стоит 5 AP, персонаж с 5 AP делает 1 выстрел, а с 9 AP — тоже 1 выстрел, так как на 2 не хватает). *Предложение*: масштабировать базу: $6 + \text{AGI}$ (диапазон от 7 до 16 AP). Выстрел пистолета — 4 AP, прицельный — 6 AP, винтовка — 7 AP. Это откроет глубокую тактическую комбинаторику. |
| **Evasion / AC** | **Изменить** | *Текущее*: $\text{AGI} \times 2 + \lfloor\text{LCK}/2\rfloor$ в процентах. *Предложение*: переход на класс защиты/уклонения в формате D20. Базовый AC (Armor Class / Защита): $10 + \text{AGI Mod} + \text{Броня}$. Атакующий должен выбросить d20 + атака $\ge$ AC цели. |
| **Initiative** | **Оставить** | Текущая механика $(\text{PER} \times 2) + \text{AGI} + \text{d20 roll}$ отлично работает и отражает вклад сенсорики и моторики. |
| **Carry Weight** | **Изменить** | *Текущее*: $20 + (\text{STR} \times 8)$ кг. *Предложение*: добавить градации перегруза вместо бинарного «иду / не иду»: Легкая загрузка (0–50%), Средняя (51–80%), Тяжелая (81–100%, -2 AP), Перегруз (>100%, невозможность бега, утроенный расход выносливости и жажды). |
| **Critical Chance** | **Изменить** | Привязать критический удар не только к LCK, но и к точному прицеливанию: Базовый шанс = $\text{LCK} \times 1\%$. При прицельном выстреле в уязвимую зону (глаза/стык брони) добавляется бонус от PER. |
| **Damage Resistance (DR/DT)** | **Изменить** | Разделить защиту брони на **Damage Threshold (DT)** (порог урона: плоская броня, отсекающая мелкие пули) и **Damage Resistance (DR)** (процентное поглощение тяжелого урона). |
| **Mental Resolve / Stress** | **Добавить** | **Новый параметр**: Ментальная устойчивость. Рассчитывается от $(\text{CHA} + \text{INT} + \text{END})$. Расходуется от ужасов пустоши, боли, бессонницы. Падение до нуля вызывает панику, галлюцинации или ступор в бою. |
| **Metabolism Rate** | **Добавить** | **Новый параметр**: Скорость метаболизма. Зависит от $\text{STR} + \text{END} - \text{AGI}$. Определяет, насколько быстро персонаж сжигает калории и воду при активных физических действиях. |

## 7. Связь с Survival и Состоянием персонажа

Система выживания не является изолированной мини-игрой. Каждое состояние транслируется в боевые и небоевые проверки через универсальный интерфейс состояний.

### 7.1. Модель физиологических потребностей и состояний

```
                                  [Физиологические нужды]
                ┌──────────────────────────┼─────────────────────────┐
                ▼                          ▼                         ▼
         Голод (0-100)               Жажда (0-100)            Усталость (0-100)
                │                          │                         │
                ├──────────────────────────┼─────────────────────────┤
                ▼                          ▼                         ▼
         [Снижение STR/Carry]       [Снижение AP/Падение]     [Штраф PER/Помеха на D20]
                                           │
                                           ▼
                                  [Критические Состояния]
                ┌──────────────────────────┼─────────────────────────┐
                ▼                          ▼                         ▼
         Радиация (радс)             Инфекции/Болезни          Травмы конечностей
       (Снижение макс. HP)         (Лихорадка, сепсис)      (Сломана нога = -50% AP,
                                   (Утечка выносливости)    сломана рука = нет 2H оруж.)
```

### 7.2. Категории состояний (Conditions & Afflictions)

1. **Голод (Hunger)**:
   - *Стадия 1 (Сыт, 0–25)*: норма.
   - *Стадия 2 (Голоден, 26–50)*: урчание в животе (-1 к скрытности).
   - *Стадия 3 (Истощен, 51–75)*: мышечная слабость (-2 STR, -15% Carry Weight).
   - *Стадия 4 (Дистрофия, 76–100)*: дистрофия (-4 STR, -2 END, постепенная потеря HP).
2. **Жажда (Thirst)**:
   - Быстрее всего наступает в бою и на жаре. Влияет на концентрацию и выносливость: падение AP, снижение уклонения, затуманивание зрения (-2 PER).
3. **Усталость / Бессонница (Fatigue / Sleep Deprivation)**:
   - Истощение ЦНС. При накоплении усталости персонаж получает **помеху (Disadvantage) на все ментальные проверки (INT, PER, CHA)**, а шанс критического провала увеличивается.
4. **Радиация (Radiation)**:
   - Радиация не просто отнимает текущее здоровье, она **блокирует максимальный пул HP** (механика отсечения красной зоны, как в Fallout 4). При 500 радс персонаж теряет 50% максимального объема здоровья до прохождения дезактивации.
5. **Травмы анатомических зон (Crippled Limbs)**:
   - *Голова*: потеря ориентации, туннельное зрение, штраф к PER и INT.
   - *Руки*: невозможность перезарядить двуручное оружие одной сломанной рукой, штраф к меткости -5.
   - *Ноги*: падение скорости передвижения, удвоенная стоимость перемещения в AP.
   - *Торс*: потеря дыхания, постоянное падение выносливости при беге, риск внутреннего кровотечения.
6. **Зависимости (Addictions)**:
   - Прием мощных химикатов (стимуляторы, психо, ментаты) дает временный буст, но при окончании действия наступает ломка (Withdrawal): резкое падение характеристик ниже исходного уровня до приема новой дозы или детоксикации.

### 8.2. Ранговая система прогрессии навыков (Mastery Levels)
Вместо микро-приростов (+1% к навыку) каждый навык имеет 4 дискретных ранга:
- **Ранг 0 (Untrained)**: базовый модификатор характеристики.
- **Ранг 1 (Novice, +2)**: базовое понимание, открывает стандартные проверки и базовые рецепты крафта.
- **Ранг 2 (Adept, +4)**: профессионал, открывает доступ к сложным механизмам и специализированным перкам.
- **Ранг 3 (Master, +6)**: виртуоз пустоши, открывает пассивные спец-способности (например, стрельба вслепую, крафт армейских патронов).

## 9. Концепция Особенностей (Traits)

**Traits (Особенности)** выбираются **только на этапе создания персонажа** (максимум 2) и представляют собой фундаментальные **обоюдоострые клинки**: дают колоссальное преимущество в одной сфере ценой тяжелого изъяна в другой.

### Примеры проектируемых Traits:

1. **«Тяжелая кость» (Heavy Framed)**:
   - *Плюс*: +2 к Силе, конечности значительно труднее сломать (порог перелома увеличен на 50%).
   - *Минус*: вес персонажа увеличен на 30 кг; падение с любой высоты наносит двойной урон; скрытность в помещениях получает постоянную помеху.

## 10. Концепция Способностей (Perks)

**Perks (Способности)** приобретаются по мере развития персонажа (например, каждые 3–4 уровня) и служат **качественными модификаторами правил игры**, а не банальными «+5% к урону».

### Примеры проектных Perks:

1. **«Анатомический хирург» (Combat Medic)**:
   - *Требования*: INT 6, Medicine Ранг 2.
   - *Эффект*: стимуляторы останавливают кровотечение мгновенно; при прицельной стрельбе по живым целям отображаются точные зоны внутренних органов и критический урон увеличивается на 50%.
2. **«Бегущий по теням» (Silent Death)**:
   - *Требования*: AGI 7, Stealth Ранг 2.
   - *Эффект*: первая атака из скрытности холодным оружием со спины наносит пятикратный урон и не прерывает режим скрытности, если цель погибла мгновенно.
3. **«Смертельный рикошет» (Lucky Bounce)**:
   - *Требования*: LCK 8.
   - *Эффект*: при промахе огнестрельным оружием в помещении пуля с шансом 30% рикошетит в ближайшего другого врага с полным уроном.
4. **«Дипломат под прикрытием» (Silver Tongue)**:
   - *Требования*: CHA 7, Persuasion Ранг 2.
   - *Эффект*: в диалогах открываются варианты «подружиться с противником», снижающие сложность подкупа на 50% и позволяющие избежать половины обязательных случайных боев на карте.
5. **«Живой таран» (Battering Ram)**:
   - *Требования*: STR 8, END 7.
   - *Эффект*: позволяет выбивать запертые деревянные и металлические двери телом без инструментов ценой небольшого расхода выносливости; в бою сбивает с ног противников при рывке.

## 12. Предлагаемая концептуальная структура данных (Data Contract)

```typescript
// 1. Базовые характеристики
export type SpecialStat = 'STR' | 'PER' | 'END' | 'CHA' | 'INT' | 'AGI' | 'LCK';

export type SpecialAttributes = Record<SpecialStat, number>; // Диапазон 1..10

// 2. Система модификаторов (Modifier Engine)
export type ModifierTarget = 
  | SpecialStat 
  | 'MAX_HP' | 'MAX_AP' | 'AC' | 'INITIATIVE' | 'CARRY_WEIGHT' | 'CRIT_CHANCE'
  | 'SKILL_ALL' | string; // конкретный ID навыка

export interface StatModifier {
  id: string;
  source: 'TRAIT' | 'PERK' | 'CONDITION' | 'EQUIPMENT' | 'DRUG' | 'SYNERGY';
  target: ModifierTarget;
  type: 'FLAT' | 'PERCENTAGE' | 'ADVANTAGE' | 'DISADVANTAGE';
  value: number;
  durationTurns?: number;
}

// 3. Состояния и выживание (Conditions & Afflictions)
export interface SurvivalMetrics {
  hunger: number;    // 0..100
  thirst: number;    // 0..100
  fatigue: number;   // 0..100
  radiation: number; // Накопленные радс (0..1000)
  stress: number;    // Ментальный стресс (0..100)
}

export interface AnatomyHealth {
  head: { hp: number; maxHp: number; isCrippled: boolean };
  torso: { hp: number; maxHp: number; isCrippled: boolean };
  leftArm: { hp: number; maxHp: number; isCrippled: boolean };
  rightArm: { hp: number; maxHp: number; isCrippled: boolean };
  leftLeg: { hp: number; maxHp: number; isCrippled: boolean };
  rightLeg: { hp: number; maxHp: number; isCrippled: boolean };
}

export interface ActiveCondition {
  id: string;
  name: string;
  severity: 'MILD' | 'MODERATE' | 'SEVERE' | 'CRITICAL';
  modifiers: StatModifier[];
}

// 4. Навыки
export type SkillRank = 0 | 1 | 2 | 3; // 0=Untrained, 1=Novice(+2), 2=Adept(+4), 3=Master(+6)

export interface SkillDefinition {
  id: string;
  name: string;
  primaryStat: SpecialStat;
  secondaryStat?: SpecialStat;
  rank: SkillRank;
}

// 5. Проверки (D20 Resolution Engine)
export interface ActionCheckRequest {
  attribute: SpecialStat;
  skillId?: string;
  dc: number;
  circumstanceModifier?: number;
  allowedTools?: string[];
  description: string;
}

export interface ActionCheckResult {
  naturalRoll: number;     // 1..20
  attributeModifier: number;
  skillBonus: number;
  toolBonus: number;
  conditionPenalty: number;
  totalScore: number;
  targetDC: number;
  outcome: 'CRITICAL_SUCCESS' | 'SUCCESS' | 'SUCCESS_WITH_COST' | 'FAILURE' | 'CRITICAL_FAILURE';
  narrativeFeedback: string;
}

// 6. Корневой объект Персонажа (Character Aggregate Root)
export interface CharacterModel {
  id: string;
  name: string;
  level: number;
  experience: number;
  unspentSkillPoints: number;
  unspentPerkPoints: number;

  baseSpecial: SpecialAttributes;
  traits: string[];
  perks: string[];

  skills: Record<string, SkillDefinition>;
  survival: SurvivalMetrics;
  anatomy: AnatomyHealth;
  conditions: ActiveCondition[];

  derived: {
    maxHp: number;
    currentHp: number;
    maxAp: number;
    armorClass: number;
    damageThreshold: number;
    damageResistance: number;
    initiative: number;
    carryWeightMax: number;
    critChancePercent: number;
    resolve: number;
  };
}
```

## 15. Потенциальные технические риски и развилки

1. **Модель проверок**: Рекомендуется D20 с Advantage/Disadvantage и границами «Успеха с ценой» для баланса азарта и контроля над фрустрацией.

3. **Мульти-путевое разрешение ситуаций**: Реализовать генератор проверок по тегам препятствий (`[Mechanical Lock]`, `[Electronic Terminal]`), предотвращающий раздувание ручного скриптинга квестов.
