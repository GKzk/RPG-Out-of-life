# OUT OF LIFE — МАТРИЦА НАВЫКОВ

> Рабочая спецификация RPG-навыков.
> Репозиторий: GKzk/RPG-Out-of-life
> Версия: 0.1
> Дата: 25.09.2026
>
> Цель: создать достаточно глубокую систему навыков без «мёртвых» навыков, которые игрок почти никогда не выбирает.

## 1. Принцип системы навыков

Навык отвечает не за один конкретный предмет или редкую ситуацию, а за устойчивый класс игровых действий.

Для каждого навыка должны выполняться условия:

1. Он полезен с начала игры.
2. У него есть применение вне одного типа контента.
3. Он имеет несколько способов проявления.
4. Он может быть полезен на ранней, средней и поздней стадии.
5. Его нельзя полностью заменить одним универсальным предметом.
6. Он не должен быть обязательным для прохождения игры.
7. Высокий уровень должен открывать новые возможности, а не только увеличивать процент успеха.
8. Низкий уровень не должен означать, что соответствующая игровая система полностью исчезает.
9. Навык не должен дублировать другой навык настолько сильно, чтобы один из них становился очевидно хуже.

В качестве антипримера учитывается проблема классических RPG, где отдельный Throwing/Метание существовал, но его практическая ценность часто была слишком низкой из-за редкости и слабости подходящего снаряжения. Подобная проблема в нашей системе не должна повторяться.

Это достаточно много для разных специализаций, но меньше, чем набор из множества узких навыков, каждый из которых требует отдельной поддержки контентом.

## 4. Физические навыки

### Атлетика — STR + END / AGI

Используется для прыжков, лазания, бега, плавания, преодоления препятствий, перемещения тяжёлых объектов, физического перемещения в бою, удержания позиции и других силовых/динамических действий.

Атлетика не заменяет Силу: STR определяет потенциал, навык — подготовку.

### Скрытность — AGI + PER

Используется для бесшумного перемещения, скрытого наблюдения, проникновения, скрытого занятия позиции, незаметного ухода, скрытных действий в бою и контроля шума.

Высокий навык должен открывать новые способы прохождения, а не только уменьшать радиус обнаружения.

### Ловкость рук — AGI + INT

Используется для кражи, незаметной передачи/изъятия предметов, работы с мелкими механизмами, обезвреживания отдельных устройств, скрытого использования предметов и тонкой ручной работы.

Кража не выделяется в отдельный навык: Ловкость рук отвечает за физическое действие, Скрытность — за незаметность, Обман/Влияние — за социальные последствия.

### Безоружный бой — AGI + STR

Используется для ударов, блоков, захватов, бросков, обезоруживания и специальных приёмов.

Должен иметь полноценную ветку развития, чтобы безоружный стиль был самостоятельным билдом.

### Ближний бой — STR + AGI

Используется для ножей, дубинок, топоров, молотков, копий и другого холодного/ударного оружия.

Не создавать отдельный навык для каждого типа оружия. Разные виды оружия используют разные соотношения STR/AGI и собственные свойства.

## 5. Оружие и тактика

### Огнестрельное оружие — PER + AGI

Охватывает пистолеты, револьверы, винтовки, дробовики и автоматическое оружие.

Используется для прицеливания, оценки дистанции, контроля отдачи, выбора точки поражения и эффективного применения разных типов огнестрельного оружия.

Не дробить систему на Small Guns / Big Guns / Rifles. Конкретное оружие получает собственные требования и модификаторы.

### Взрывчатка — INT + PER

Используется для гранат, мин, самодельных взрывных устройств, обезвреживания, установки зарядов, оценки радиуса поражения и инженерных разрушений.

Отдельного «Метания» нет: бросок гранаты является частью Взрывчатки. Бросок обычного предмета относится к Атлетике/Ловкости рук в зависимости от контекста.

## 6. Выживание и исследование

### Выживание — END + PER

Используется для поиска безопасного места, огня, воды, полевой подготовки, оценки ресурсов, выживания в плохих условиях, снижения последствий голода/жажды/холода, приготовления простой пищи и лагеря.

Высокое Выживание должно менять поведение игрока в мире, а не только уменьшать расход ресурсов.

### Поиск — PER + INT

Используется для тайников, скрытых предметов, следов, осмотра помещений, полезных материалов, доказательств и несоответствий.

Поиск отвечает на вопрос «что здесь можно обнаружить?», а Наука/Интеллект — «что означает найденное?».

### Ориентирование — PER + INT

Используется для навигации, чтения местности, определения направления, оценки расстояния, планирования маршрута, карт, обходных путей и движения при ограниченной видимости.

## 7. Технические навыки

### Медицина — INT + PER

Один навык покрывает медицинскую систему: первая помощь, лечение ран, диагностика, травмы, стабилизация, медицинское оборудование, подготовка медицинских средств и помощь NPC.

Отдельные First Aid и Doctor не вводятся, чтобы не создавать два навыка с почти одинаковой функцией.

### Механика — INT + AGI

Ремонт механизмов, оружия, транспорта, генераторов, двигателей, механических систем и диагностика неисправностей.

### Электроника — INT + PER

Ремонт электронных устройств, восстановление питания, терминалы, датчики, безопасность, радиосвязь и старые электронные системы.

Особенно важна для исследования технологического наследия мира.

### Наука — INT + PER

Анализ неизвестных устройств, старых технологий, химических/биологических объектов, данных и документов; исследовательские проверки и открытие новых способов применения предметов.

Наука не должна превращаться в «ещё один ремонт».

### Изготовление — INT + AGI

Создание и переработка предметов, боеприпасов, инструментов, улучшений оборудования и специализированных ресурсов.

Отличие от Механики:

- Механика — ремонт и работа с существующей системой.
- Изготовление — создание/переработка.

## 8. Социальные навыки

### Убеждение — INF + INT

Аргументация, переговоры, убеждение, дипломатия, получение добровольной помощи и мирное разрешение конфликтов.

Результат зависит также от отношений, репутации, аргументов, знаний, предыдущих поступков и ситуации.

### Торговля — INF + INT

Покупка, продажа, обмен, переговоры о цене, оценка сделки, поиск товаров и коммерческие договорённости между поселениями.

Экономическая ценность навыка должна поддерживаться дефицитом и различиями между поселениями.

### Обман — INF + PER

Ложь, сокрытие намерений, выдача себя за другого в допустимых ситуациях, создание ложной версии событий, отвлечение и провокация.

Высокий навык не должен автоматически убеждать любого NPC: учитываются знания и отношение NPC.

### Лидерство — INF + WIL

Управление союзниками, организация людей, командные решения, разрешение внутренних конфликтов, временные союзы и потенциальное управление поселением.

Один из потенциально важных навыков поздней игры.

### Обращение с животными — WIL + INF

Успокоение, обучение, уход, оценка поведения, предотвращение нападения и взаимодействие с питомцем.

Особенно важен для системы питомца.

## 9. Почему нет узких навыков

Вместо First Aid + Doctor используется Медицина.

Вместо Throwing используется Атлетика + Взрывчатка.

Вместо Steal используется Ловкость рук + Скрытность + социальный контекст.

Вместо Barter используется Торговля.

Принцип: объединяем механики там, где разделение не создаёт отдельного полноценного стиля игры.

## 11. Контроль «мёртвых навыков»

Перед реализацией каждый навык должен пройти четыре теста:

1. **Частота:** встречается регулярно.
2. **Разнообразие:** имеет несколько типов применения.
3. **Независимость:** открывает возможности, которые нельзя полностью заменить другим навыком.
4. **Развитие:** рост меняет возможности, а не только вероятность.

Например:

- Механика 20 — простейший ремонт.
- Механика 50 — сложные механизмы и оборудование.
- Механика 80 — редкие системы и уникальные способы взаимодействия с техникой.

Аналогичный принцип применяется ко всем навыкам.

## 12. Необязательность навыков

Оптимальный персонаж не должен быть обязан прокачивать Механику, Мицину, Огнестрельное оружие и Поиск одновременно.

Для большинства задач должны существовать альтернативы:

- другой путь;
- другой предмет;
- NPC-специалист;
- покупка услуги;
- силовое решение;
- социальное решение;
- поиск информации;
- временный обходной вариант.

Это необходимо для нелинейности игры.

## 13. Следующая проверка

До окончательного утверждения списка нужно прогнать 20 навыков через реальные игровые ситуации:

- создание персонажа;
- первая локация;
- исследование;
- первый бой;
- первый ремонт;
- первая торговля;
- первый серьёзный диалог;
- первая экспедиция;
- первые сюжетные развилки.

Для каждого сценария проверяется, что развитый навык даёт значимую возможность, а отсутствие навыка не блокирует игру полностью.

После этой проверки фиксируются:

1. окончательный список навыков;
2. уровни навыков;
3. формулы проверок;
4. пороги и уровни мастерства;
5. взаимодействия с перками;
6. взаимодействия с предметами;
7. только затем — конкретные перки.
