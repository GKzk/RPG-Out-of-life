# OUT OF LIFE — REAL SCENARIO SKILL TEST v0.2

> Дата: 25.09.2026
> Статус: scenario stress test — 22 навыка
> Цель: проверить самостоятельную игровую функцию всех 22 навыков после добавления Исполнения и Проницательности.

## Методика

Для каждого навыка проверяется:
1. естественная игровая ситуация;
2. самостоятельный результат;
3. альтернатива без навыка;
4. отсутствие критического дублирования;
5. полезность на разных стадиях;
6. отсутствие обязательности для единственного прохождения.

Рабочая числовая модель проверки остаётся прежней: Attribute + Skill + Equipment + State + Context + Preparation против Difficulty. Этот тест проверяет прежде всего функциональный дизайн, а не заменяет математический баланс.

## Отдельный стресс-тест Проницательности

### Сцена A — ложь без физических доказательств
NPC сообщает правдоподобную, но неполную историю.

- Поиск не помогает, если физической улики рядом нет.
- Проницательность может выявить несоответствие поведения и рассказа.
- Результат не должен быть «NPC лжёт», а должен давать информацию уровня «что-то не сходится / он скрывает часть истории».

**PASS.**

### Сцена B — NPC говорит правду, но герой неверно понимает ситуацию
Высокая Проницательность не должна превращаться в универсальную способность получать правильный ответ. Проверка должна учитывать доступную информацию.

**PASS / GUARDRAIL.**

## Проверка обязательности

Ни один из 22 навыков не должен быть единственным способом завершения основной сюжетной задачи.

Особое внимание:
- Проницательность не должна быть обязательна для понимания главной истории;
- Исполнение не должно требоваться для прохождения основного квеста;
- специальные сцены могут иметь уникальные преимущества этих навыков.

## Контрольные точки прогрессии

Для всех 22 навыков сохраняются ступени:
- 0–19: новичок;
- 20–39: обученный;
- 40–59: компетентный;
- 60–79: специалист;
- 80–99: эксперт;
- 100: мастер.

Переходы должны открывать новые способы действия, а не только увеличивать вероятность успеха.
