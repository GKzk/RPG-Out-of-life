# OUT OF LIFE — REAL SCENARIO SKILL TEST

> Версия: 0.1
> Дата: 25.09.2026
> Статус: design stress test
>
> Цель: прогнать все 20 канонических навыков через конкретные игровые ситуации до миграции в код.

## 1. Методика

Тестируется не только шанс проверки, но и игровая функция навыка:

1. есть ли естественная ситуация, где навык нужен;
2. меняет ли высокий навык способ решения, а не только вероятность;
3. существует ли разумная альтернатива;
4. не дублирует ли навык соседний;
5. работает ли навык на разных стадиях развития;
6. не превращается ли он в обязательный универсальный ключ.

Для числовой контрольной точки использован персонаж с основной характеристикой 7 и рабочим навыком 45–70. Формула:

Base = Attribute × 4 + Skill × 0.6

Контекст/оборудование добавляются отдельным модификатором. Это не runtime-тест: текущая 20-навыковая система ещё не мигрирована в src.

## 3. Числовой контроль

Использован рабочий диапазон Difficulty 20/35/50/65/80/100 и внешние модификаторы из SKILL_CHECK_BALANCE.

Контрольные примеры:

- Атлетика 50 + STR 7: Base 58 против Difficulty 50 → задача практически надёжна; это соответствует обычному физическому препятствию.
- Скрытность 60 + AGI 7 + благоприятный контекст +5: 69 против Difficulty 65 → сложная задача становится рабочей для подготовленного специалиста.
- Взрывчатка 45 + INT 7 против Difficulty 65: Base 46? Нет: 28 + 27 = 55 → без оборудования/подготовки задача слишком рискованна; это допустимо для опасной мины, но обязательны альтернативы и специализированное оборудование.
- Медицина 70 + INT 7 + тяжёлая рана −5: 65 против Difficulty 65 → специалист находится около границы; результат зависит от времени и качества оборудования.
- Убеждение 55 + INF 7 + хорошая репутация/аргументы +5: 66 против Difficulty 60 → социальная задача решаема, но NPC не обязан соглашаться вопреки интересам.

Важно: эти числа проверяют поведение формулы, а не фиксируют Difficulty конкретных сцен.

## 4. Проверка стадий прогрессии

Для каждого навыка должна сохраняться следующая логика:

### 0–19
Простые действия остаются возможными, но специализированные способы в основном закрыты.

### 20–39
Появляется базовая профессиональная компетентность и первые специализированные варианты.

### 40–59
Персонаж уверенно решает обычные профессиональные задачи и получает первые качественные альтернативы.

### 60–79
Открываются сложные/опасные способы решения и работа в неблагоприятных условиях.

### 80–99
Появляются редкие, экспертные и высокорисковые варианты.

### 100
Мастерство должно открывать уникальные способы применения, а не превращать любой бросок в автоматический успех.

## 5. Проверка дублирования

### Ловкость рук vs Скрытность
Разделение работает:
- Ловкость рук = физически сделать действие;
- Скрытность = не быть обнаруженным.

Кража может потребовать оба фактора, но не два последовательных броска без необходимости.

### Механика vs Электроника
Граница должна быть функциональной:
- Механика = механические системы, двигатель, оружие, генератор;
- Электроника = цепи, датчики, терминалы, питание, электронная безопасность.

Гибридное устройство должно иметь основной навык по типу отказа, а не требовать оба навыка.

### Электроника vs Наука
Разделение работает:
- Электроника отвечает «как безопасно вмешаться в систему»;
- Наука отвечает «что это и как оно работает на уровне неизвестного объекта».

### Механика vs Изготовление
Разделение работает:
- Механика = восстановить существующее;
- Изготовление = создать/переработать.

### Убеждение vs Обман vs Торговля
Разделение работает:
- Убеждение = изменить решение через аргументы;
- Обман = изменить восприятие фактов/намерений через ложь;
- Торговля = обменять ресурсы на выгодных условиях.

### Поиск vs Ориентирование
Разделение работает:
- Поиск = обнаружить информацию/объект в текущей сцене;
- Ориентирование = определить положение и маршрут между точками.

### Выживание vs Ориентирование
Есть потенциальное пересечение, но оно контролируемо:
- Выживание = обеспечить существование и ресурсы;
- Ориентирование = перемещение и навигация.

## 6. Найденные проблемы

### P1 — Взрывчатка
При навыке 45 и INT 7 сложная мина (Difficulty 65) без оборудования даёт Base 55 и очень высокий риск.

Это само по себе не проблема: обезвреживание мины действительно должно быть опасным. Проблема появится, если аналогичные проверки будут часто обязательными.

**Требование:** у опасных взрывчатых ситуаций должна быть альтернативная ветка: обход, специалист, отключение питания, дистанционный подрыв или другой способ.

### P2 — Электроника
Нужно строго отделять электронный замок от механического замка. Иначе Ловкость рук, Механика и Электроника начнут конкурировать за одну и ту же дверь.

**Требование:** тип системы должен определять основной навык.

### P3 — Социальные навыки
Нельзя строить сюжет на «одной кнопке Убеждение». Для важных NPC должны учитываться:
- интересы;
- отношения;
- известная информация;
- аргументы;
- репутация;
- альтернативные действия.

### P4 — Обращение с животными
Навык станет мёртвым, если в игре будет только один обязательный питомец и 2–3 сцены.

**Требование:** поддержать его дикими животными, питомцами, вьючными животными, охраной, следами/поведением и несколькими мирными/боевыми сценариями.

### P5 — Лидерство
Навык должен быть полезен не только в бою. Его долгосрочная зона — группа, поселения, переговоры между людьми, распределение задач и организация.

## 7. Итог

По результатам ручного сценарного стресс-теста:

- 20/20 навыков имеют естественные игровые ситуации;
- 20/20 имеют потенциально самостоятельную зону компетенции;
- явного мёртвого навыка не обнаружено;
- критических дубликатов нет;
- 5 зон требуют явных предохранителей контента: Взрывчатка, Электроника, социальные навыки, Обращение с животными, Лидерство;
- базовую формулу менять по итогам этого теста не требуется.
